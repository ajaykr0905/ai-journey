# Reproducible public-data SFT fine-tuning

Day 68 turns the sealed 500-example Databricks Dolly dataset from Day 67 into a
bounded supervised fine-tuning experiment. The installed workflow trains a tiny
byte-level decoder for eight CPU float64 optimizer steps, scores exactly the same
held-out assistant targets before and after training, records greedy completions,
and seals the complete comparison for independent verification and exact replay.

## Build, verify, and replay

First build the Day 67 dataset from its pinned public snapshot. Then run:

```bash
ai-journey-sft-finetune build \
  --dataset artifacts/day-67-sft-dataset/chatml.jsonl \
  --config config/day-68-sft-finetune.json \
  --output artifacts/day-68-sft-finetune.json

ai-journey-sft-finetune verify \
  --dataset artifacts/day-67-sft-dataset/chatml.jsonl \
  --report artifacts/day-68-sft-finetune.json

ai-journey-sft-finetune replay \
  --dataset artifacts/day-67-sft-dataset/chatml.jsonl \
  --report artifacts/day-68-sft-finetune.json
```

The source loader requires bounded, newline-terminated, non-symlink JSONL bytes
and binds the report to their SHA-256 digest. Assistant character spans are
converted to UTF-8 byte spans before windowing, so Unicode responses supervise
all of their bytes. Windows never cross example boundaries. The deterministic
schedule selects training windows only; validation examples are used only by the
matched before/after likelihood and generation comparison.

## Evidence contract

The model uses a fixed 256-byte vocabulary, one transformer layer, no dropout,
one CPU thread, and float64 parameters. The report records configuration, dataset
counts and digest, schedule digest, initial/final model identities, every loss and
gradient norm, supervised-token exposure, held-out NLL/perplexity, greedy token
outputs, runtime controls, and explicit limitations. Verification checks the
sealed structure and exact dataset identity. Replay reruns training and requires
the entire report to match byte-for-byte after canonical JSON serialization.

Atomic report and checkpoint replacement prevent a failed write from exposing a
partial artifact. Checkpoints bind model and optimizer state to the configuration,
dataset digest, schedule digest, completed step, and CPU RNG. Segmented training
is regression-tested against the same one-shot schedule.

## Interpretation limits and learner evidence

This is a character-scale engineering diagnostic, not a useful aligned model. It
does not demonstrate GPU training, distributed execution, production readiness,
factuality, harmlessness, PPO, DPO, preference optimization, or a model-quality
improvement. Eight updates and eight validation examples are deliberately small
CI controls. A lower held-out assistant NLL is a measurement on this fixed slice,
not evidence of general alignment; greedy byte outputs may contain replacement
characters when generated bytes are not valid UTF-8.
