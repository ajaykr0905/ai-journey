# Triage labels

The engineering skills use five canonical triage roles. Use the corresponding repository label whenever a skill names one of these roles.

| Canonical role | Repository label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required. |
| `needs-info` | `needs-info` | More information is required from the reporter. |
| `ready-for-agent` | `ready-for-agent` | The work is fully specified for an implementation agent. |
| `ready-for-human` | `ready-for-human` | The work requires human implementation or judgment. |
| `wontfix` | `wontfix` | The work will not be actioned. |
